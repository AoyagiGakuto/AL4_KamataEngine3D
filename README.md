# 11月分進歩
## 操作方法
WASDで移動
Wキーでジャンプ(二段ジャンプ可)
Wキー長押しで滞空
Hキーで弾を発射
Yキーで降ってくるゆっくりになる弾
Kキーで近接攻撃
Rキーで必殺技
シフトでロックオン(Lでロックオンの切り替え)
