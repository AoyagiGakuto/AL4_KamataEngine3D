# 1月分進歩
## 操作方法
- WASDで移動
- Wキーでジャンプ(二段ジャンプ可)
- Wキー長押しで滞空
- Hキーで弾を発射
- Rキーで必殺技
- シフトでロックオン
- Lでロックオンの切り替え

- Yキーで降ってくるゆっくりになる弾 (ロックオン状態のみ可能)
- Kキーで近接攻撃、空中攻撃 (ロックオン状態のみ可能)
- Kキー長押しでチャージ攻撃 (ロックオン状態のみ可能)
- Kキー後ろで敵打ち上げ空中だと叩きつけ (ロックオン状態のみ可能)

## 今月の成果一覧
- 成果１
  - 敵を倒すと時間が増えるようにしました。
- 成果2
  - 弾の強さを少し下方しました。
- 成果3
  - ファイル整理をしました。
## その他
 - 貫通弾になにか利点を作る。
 - 操作を難しくしない。
 - 近接でたおすと制限時間が増える。
 ように改良しています。
