# 11月分進歩
## 操作方法
WASDで移動
スペースでジャンプ(二段ジャンプ可)
スペース長押しで滞空
Hキーで弾を発射
シフトでロックオン(Lでロックオンの切り替え)
Rキーで必殺技
Kキーで近接攻撃
Yキーで降ってくるゆっくりになる弾
